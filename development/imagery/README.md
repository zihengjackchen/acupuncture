# Imagery development archive

Original paintings, generation prompts, and earlier exports live here. The website serves selected WebP files from `static/images/editorial/`; these source collections are not published.

- `editorial/`: first-generation originals and archived `webp-v1/` exports.
- `editorial-inkwash-v2/`: botanical paintings used for current service cards, plus reserve artwork.
- `editorial-inkwash-v3/`: current figurative paintings and unused reserve originals.
- `editorial-inkwash-v4/`: rejected likeness edits, preserved with their prompts; not deployed.
- `legacy-reference/`: the three original illustrations referenced by the historical `IMAGE_PROMPTS.md` brief.

Each collection's `prompts.json` keeps the prompt, original PNG path, and generation history. `historicalOutput` and `historicalResponsive` record exports removed from production. The historical brief describes an earlier site layout; current assignments are in `content/` and `layouts/`.
