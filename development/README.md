# Development sources and design history

This directory is kept in the repository and is not published by Hugo.

- [Brand explorations](brand/options/README.md): logo options A–G, previews, earlier spacing and wallpaper layouts.
- `brand/original/`: the original logo artwork used by the current exporter.
- `brand/archive-original-a/` and `brand/archive-v1/`: earlier identity packages and exporter snapshots.
- `imagery/`: generated PNG originals, prompts, reserved paintings, and rejected artwork.
- [Original image brief](imagery/IMAGE_PROMPTS.md): reference notes for the first illustration collection.

Current downloadable assets live in [`media-pack/`](../media-pack/). The website uses `static/images/brand/` and `static/images/editorial/`; active brand masters and source fonts remain in `assets/brand/`.

Run `npm.cmd run brand` from the repository root to rebuild the current identity. Archived exporters are historical references and should not replace the active generator.
